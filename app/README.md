# Silent Link — React Native App (Phase 1c: Gesture → Text)

Offline-first ISL gesture recognizer. Live camera → on-device MediaPipe Hand
Landmarker → 40-frame normalized buffer → on-device ST-GCN (ONNX) classifier →
recognized gloss/text.

## ⚠️ Native build required (not Expo Go)

This screen uses native modules — `react-native-vision-camera` (frame
processor), the MediaPipe hand-landmarker Kotlin plugin, and
`onnxruntime-react-native` — so it **cannot run in Expo Go**. Build a dev
client with a custom native project:

```bash
npm install
npx expo prebuild --clean
npx expo run:android     # requires Android SDK + a device/emulator
```

The native `android/` folder is generated by `expo prebuild` and is gitignored;
regenerate it whenever `app.json` plugins change.

> iOS is not yet wired (the MediaPipe plugin is Android-only). iOS support
> needs a separate native module and a macOS build machine.

## Architecture

```
Camera (vision-camera v4, front/back toggle)
  └─ useFrameProcessor → detectHandLandmarks(frame)   [native worklet]
        └─ runOnJS → useGestureRecognizer.ingest(detection)
              ├─ pack + normalize hands -> (42, 3) frame   src/model/normalize.ts
              ├─ buffer 40 frames                          src/hooks/useGestureRecognizer.ts
              └─ onnxruntime predicts ST-GCN -> top gloss  src/model/classifier.ts
                    └─ render label + confidence           src/screens/GestureScreen.tsx
```

- `src/model/normalize.ts` — mirrors `model/src/data/normalize.py` (left-hand
  rows first, wrist-relative, scale-invariant) so on-device inputs match training.
- `src/config/glosses.ts` — reads the bundled `glosses.json`; the class order
  matches training (`sorted(glosses.keys())`).
- `assets/model.onnx` — the ST-GCN ONNX classifier (self-contained, ~1.5 MB).
- `assets/hand_landmarker.task` — MediaPipe hand-landmarker model, copied to
  Android assets by the config plugin at prebuild.

## Keep app assets in sync with the trained model

The bundled `glosses.json`, `hand_landmarker.task`, and `model.onnx` are copied
from the model package by:

```bash
python scripts/sync_app_assets.py --run model/runs/<name>
```

Run this after (re)training so the app ships the latest model + vocabulary.

## Current status

The bundled `model.onnx` is a **synthetic smoke-test** model (ST-GCN trained on
`make_synthetic_data.py`). Replace it with a model trained on real captured ISL
sequences before relying on recognition accuracy.
